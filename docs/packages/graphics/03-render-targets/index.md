# Render Targets

Every example so far has drawn straight to the canvas. A `Device` can also
render into an off-screen texture instead - the basis for mirrors,
minimaps, multisampling, and post-processing effects.

1. [Render to Texture](./01-render-to-texture/) — draw a scene off-screen, then display it on a quad.
2. [MSAA & Resolve](./02-msaa-resolve/) — multisampled anti-aliasing and resolving it to the screen.
3. [Multiple Render Targets](./03-multiple-render-targets/) — writing to more than one texture in a single pass.
4. [Post-Processing](./04-post-processing/) — running a full-screen shader over a rendered scene.
