# Geometry

Hand-writing vertex data works for quads and cubes, but gets tedious fast
for anything rounder. `@gglib/graphics` ships procedural builders for the
common shapes, and a way to draw many copies of the same geometry cheaply.

1. [Geometry Builders](./01-geometry-builders/) — boxes, spheres, cylinders and more, generated on demand.
2. [Instancing](./02-instancing/) — drawing many copies of one geometry in a single call.
