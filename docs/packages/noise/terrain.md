# Noise Terrain

Bakes a noise field into a heightmap and uses it to displace a terrain mesh.
The _Uniforms_ sliders tweak the noise at runtime, the _Graph_ options build a different noise graph.
Switch the mode to _CPU_ to compute the same terrain in JavaScript. Drag to rotate, scroll to zoom.
